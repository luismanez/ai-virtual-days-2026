# Feature: Contact actions

One reusable action component for Teams contact, including a fictional-profile preview and host-link error feedback. The obsolete Schedule preview button, state and dialog were removed at the user's request on 2026-11-13. Contact creates no message or meeting; actual booking remains available through Check availability and its explicit confirmation.

Follow [GLOBAL.md](../GLOBAL.md) for the shared data, visual, safety and demo-scope contract. Do not add supporting infrastructure beyond what the session needs.

See [tasks.md](tasks.md) for the small implementation steps and [the checklist](../tasks/todo.md) for progress.
